# Прогноз посадок трамвая

## Как устроена

Прогноз = уровень маршрута × форма.

- **Форма**: доля от среднего будня маршрута в этот час этого дня. Среднее трёх моделей: профиль по медианам,
  пул из 9 LightGBM на срезах данных (все данные, будни / выходные, пик / день / вечер, группы маршрутов) и CatBoost.
  Признаки: календарь (праздничные блоки, рабочая суббота, световой день), режимы маршрутов, типичные доли часа.
- **Уровень**: средний будний день маршрута за последние 4 недели октября × 1.045, выходные × 1.04.
- **События, которых нет в истории**: ремонт по выходным на маршрутах 50 и 7 до 30.11, новый маршрут 5 с 16.12,
  бесплатная новогодняя ночь, последние рабочие дни года (29-30.12) × 0.90.
- **Калибровка** уровня по маршрутам и месяцам и рабочая суббота 01.11 подобраны по проверкам на платформе.

Все числа лежат в `tram/settings.py`.

## Состав

```
data/                  labels хакатона (train + test)
artifacts/forecast.csv готовый прогноз: route;date;hour;prediction, 14 640 строк
tram/forecast.py       пересборка прогноза
tram/reader.py         чтение прогноза для бэкенда
tram/…                 календарь, данные, признаки, модели, настройки
```

## Пересборка прогноза

```
pip install -r requirements.txt
python -m tram.forecast                      # data/ -> artifacts/forecast.csv
python -m tram.forecast --labels <папка> --out <файл> --threads 4
```

## Встраивание в бэкенд

Python: загрузить один раз при старте и вызывать из любых потоков (данные только читаются).

```python
from tram import Forecast

forecast = Forecast.load("artifacts/forecast.csv")
forecast.get(17, "2025-11-03", "2025-11-09", step="hour")   # [{"route": 17, "date": ..., "hour": 8, "boardings": 1111}, ...]
forecast.get(None, step="month")                             # все маршруты по месяцам
forecast.total("2025-12-01", "2025-12-31")
```

`step`: `hour`, `day`, `month`; без `route` возвращаются все маршруты. Неверный маршрут, период вне ноября-декабря
или неизвестный шаг дают `ValueError` с понятным текстом. Чтению нужен только numpy.

Другой язык (Java и т. п.): читать `artifacts/forecast.csv` напрямую, формат `route;date;hour;prediction`.

## Ресурсы (замер: Windows, Python 3.13)

| Задача                                  | Время                   | Память           |
| --------------------------------------- | ----------------------- | ---------------- |
| Пересборка прогноза, 4 потока           | 42 с                    | 251 МБ пик       |
| Пересборка прогноза, 1 поток            | 55 с                    | 238 МБ пик       |
| Загрузка прогноза в бэкенд              | 8 мс                    | 35 МБ на процесс |
| Запрос «маршрут за 2 месяца», 8 потоков | p50 0.09 мс, p95 0.4 мс | 5 700 запросов/с |

Пересборка нужна только при новых данных; в работе сервиса модели не загружаются.
